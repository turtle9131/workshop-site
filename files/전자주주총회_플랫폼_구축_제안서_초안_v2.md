## [7페이지] Ⅴ. **A**rchitecture — 실시간 양방향 통신 · 데이터 · 표준 연계

- 부제: Ⅳ. 표준화에 기반한 미래지향적 아키텍처 구축 (2/2)
- 핵심메시지: **내부망 WebSocket + 대용량 Message Broker로 대규모 동시접속과 무결성을 보장하고, 메타관리·자동화 배치·표준 연계로 데이터 신뢰성과 차세대 흡수성을 확보**
- 본문 ① 보안·무결성 실시간 양방향 통신:
  - WebSocket 채택 근거: 국제표준 · 풍부한 사례 · 최신 브라우저 지원 · 안정적 실시간성
  - Issue Point: 주주 인증 및 투표 위·변조 방지, 외부 원천 접근 차단, 수만 명 무지연 전송, 실시간 집계용 Message Broker 필요
  - 구성: ① **Reverse Proxy 기반 내부망 WebSocket 구축**(외부 접근 차단) ② 운영 안정성·차세대 호환을 위한 **Message Broker(Confluent)** 추가 ③ 세션관리·검증·Cluster 구성
- 본문 ② 자체 메타데이터 관리 솔루션 기반 데이터 품질: KSD 전사 데이터 표준 적용 / 舊 메타 → 제안사 메타관리 솔루션(**N·ETA**: 데이터 이관·동기화·사전점검·추출/형식변환) → 新 메타관리시스템(직접등록·일괄파일등록·이관스크립트) / 표준 적용 절차 = 표준용어 존재여부 확인 → 단어·도메인 신청 → 표준 검토·영향도 분석·승인 → 표준 반영
- 본문 ③ 배치 구성 및 데이터 신뢰성: **LazyBatch**(주총 일정 연동, 배치 연기 영향도 분석·대상 선정, 피크타임 회피 자동 시간 조정 — 연기 1시간) / 주요업무 요청 시 DB 저장 데이터 사전 정합성 **이중검증** / 공통 컴포넌트 4단계 = 업무분석·대상선정 → 공통 컴포넌트 개발 → 업무 적용 → 검증·튜닝(지속 개선)
- 본문 ④ 차세대 호환 표준 연계 모듈(전사표준: 동기 = OpenAPI(RESTful) / 비동기 = Message Broker) — 연계 대상 전수 식별 완료(10여 개):

| 구분 | 시스템 | 연계 데이터(예) | 방식 |
|---|---|---|---|
| 외부 | SignKorea | 인증서 | 동기/실시간 |
| 외부 | 카카오페이·Pass·신용평가사 | 간편인증검증·주민번호 CI 변환 | 동기/실시간 |
| 외부 | 행정안전부 | 도로명주소·모바일신분증 | 동기/실시간 |
| 내부 | UMS | SMS/MMS 안내문자 | 동기/실시간 |
| 내부 | 전자투표시스템 | 최종명부·최종결과·불통일행사 | 동기·비동기 혼합 |
| 내부 | 세이브로 | 주총일정·전자투표 업무이용정보 | 비동기/온라인배치 |
| 내부 | e-SAFE(다수 도메인) | 의결권·수수료·안건정보·계좌정보 | 동기·비동기 |

- [도식] 좌상: 외부망↔내부망 WebSocket 통신 구성도(Reverse Proxy·세션관리·Message Broker Cluster) / 우상: 메타데이터 이관 파이프라인 processFlow / 좌하: LazyBatch 자동 연기 로직(branching) / 우하: 표준 연계 모듈 구성도(Producers/Consumers)
